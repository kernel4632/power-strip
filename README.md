# DORM LAB · 生活，每一瓦都值得看见

以大学宿舍为舞台的交互式 3D 用电可视化。默认展示完整宿舍，点击电器或场景标记才展开详情；桌面采用侧边面板，手机采用底部抽屉。

## 场景与交互

- 程序化剖面宿舍：上下铺、织物床品、书桌、键盘、办公椅、窗帘、窗外建筑、书籍、软木板、背包、绿植、地毯与茶几。
- 八类可交互电器：显示器、笔记本、台灯、风扇、手机充电座、水壶、冰箱、空调。模型由本地几何与程序纹理生成，不依赖外部模型或字体请求。
- 设备动画：风扇加减速与摇头、屏幕开关、充电指示、台灯亮度、加热蒸汽、空调气流。
- 四个平滑镜头预设和设备聚焦；鼠标拖动环绕、滚轮缩放；触屏单指旋转、双指缩放。
- 日夜氛围切换；专注学习、晚间放松、离开宿舍三种设备组合。
- 可开关能流动画与设备标记；辅助设备列表支持不精确点击模型时的访问。
- 总功率、单设备功率、最近 60 个样本曲线、负载分布、本次累计电量、估算电流和演示阈值提醒。
- 静态家具按材质合批、3D 模块延迟加载、按需渲染、缓存阴影、自适应像素比及减少动态效果偏好支持。

## 开发

使用 Node.js 22.12+，建议与现有环境保持一致。

```bash
npm ci
npm run dev        # 监听 0.0.0.0:46340，支持 HMR
npm run build      # 类型检查与生产构建
npm run lint
npm run typecheck
npm run preview    # 预览生产构建
```

现有服务器已使用 `power-strip-dev.service` 运行 Vite，修改源码可热更新，不要在同一端口重复启动进程。

```bash
systemctl status power-strip-dev
systemctl restart power-strip-dev
journalctl -u power-strip-dev -f
```

开发服务对公网开放，不等同于生产部署；不要放置密钥或敏感数据。生产部署应使用构建后的 `dist/`，并另行配置 HTTPS 和访问控制。

## 数据边界

**所有数值均为本地模拟，不是电表读数，也不能用于真实用电安全判断。**

- 额定/待机功率与 2200 W 演示阈值在 `src/data/catalog.ts` 集中定义，不代表设备实测参数或宿舍规定。
- 空调、冰箱与桌面电器统一进入演示能源网络；可见排插不是准确的八设备物理接线拓扑。空调线缆连接墙面，动画为示意。
- 模拟每秒采样，最多保留 90 个样本，图表显示最近 60 个；没有伪造页面打开前的历史。
- 累计电量按功率随时间积分；电流按 `P / 220 V` 简化估算，未考虑功率因数。
- 后台页面可能暂停或降频，单次积分间隔限制为 5 秒，不用于全天精确计量。
- 总电源关闭时下次采样归零；过载只提示，不模拟断路器。
- 状态仅存在当前页面内存，刷新重置。

## 源码结构

```text
src/
  App.tsx                   场景外壳、工具栏、生活模式、键盘交互
  types.ts                  电器、状态、采样和镜头类型
  data/catalog.ts           集中参数、设备位置和镜头预设
  store/usePowerStore.ts     状态、模拟采样、电量积分
  scene/
    Scene.tsx               Canvas、灯光、镜头、标记投影、渲染策略
    DormRoom.tsx            家具、建筑与生活细节
    Appliance.tsx           电器模型、屏幕、动画和鼠标事件
    PowerStrip.tsx          排插、线缆、能流粒子
    Geometry.tsx            几何构件
    StaticGeometry.tsx      静态网格按材质合批
    materials.ts            共享程序纹理
  ui/
    Hotspots.tsx            可访问的场景标记
    PowerPanel.tsx          按需设备与能源详情
    PowerChart.tsx          SVG 实时曲线
    Icon.tsx                本地 SVG 图标
```

## 验证与限制

构建与 lint 已通过；已在浏览器验证桌面/手机布局、面板展开关闭、台灯开关与亮度、设备聚焦、生活模式、超阈值提示和总电源归零。

Three.js/R3F 的 3D 分包仍会产生体积提示，浏览器中存在上游 `THREE.Clock` 弃用提示；不影响当前运行。无独立自动化测试套件。服务端无硬件 GPU 的浏览器运行较慢，动画帧率须在实际用户设备进一步测量，不能据此宣称稳定 60 FPS。
