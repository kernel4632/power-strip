## 核对结果

- 原始 24 小时数据共 12 组 × 144 个区间，逐行与合计相符。完整导入模块保留用于来源核对；网站只使用建模清单对应的数据。
- 网站保留 MacBook ×2、游戏笔记本 ×2、iPhone ×2、安卓手机 ×2、平板 ×2、台灯 ×4，共 6 类、14 台设备。空调、洗衣机、LED 照明、热水壶、吹风机、电煮锅均不展示、不计入网站合计，也不新增模型。
- 按这些设备逐时段重算：平均功率 140.048611 W、同时段合计峰值 590 W、日耗电 3.361167 kWh。峰值取合计曲线的最大值，不相加不同时刻的各组峰值。
- 各组数量列已是组合计；折算到 3D 场景单台时只除以数量，不再额外相乘。数据检查同时验证各组台数与模型数量一致。
- 插排仅展示场景采用的「公牛407四插位」（Sheet1 A10:E10），其余 11 款资料不进入界面。
- 交互仍使用记录峰值均分作为 100% 负载参考；手机、平板、MacBook 等曲线不随当前开关改变。资料表参考功率仅作说明，不覆盖时序值，也不当成单台实际耗电。
- 设备资料使用主表「宿舍设备功率」，只展示已建模设备对应的型号与参考功率。
- 原始汇总表 A19 明确说明：本表不单独证明每项是实测；若原记录使用估算，结果也属于估算。页面使用「小组收集整理，包含依据资料估读的数值」，不将这些资料升级为现场传感器实测。

## 更新方法

运行 `scripts/import-workbooks.py` 并传入三份确认过版本的附件。导入程序验证 144 个时间标签、非负数、各行合计和汇总指标，再生成数据模块。缺失数值不填零；资料模型缺失保留 `null`。

之后运行 `npm run check:data`、`npm run lint -- --deny-warnings` 和 `npm run build:pages`。Pages 工作流同样执行数据与开关回归检查，失败时不部署。
