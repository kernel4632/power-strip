## 几何检查方法

浏览器场景提供 `window.dormDiagnostics()`，读取实际 three.js 几何变换后的世界与局部包围盒，不仅依赖配置尺寸。

已验证 16 件设备：

1. 模型底部与预定支撑面高度差不超过 3 mm（本轮结果四舍五入为 0 mm）。
2. 桌面设备不超出桌面边界；柜格设备不越过侧板、背板或上板。
3. 同床位设备间没有三轴同时超过 2 mm 的包围盒交叠。
4. 四床位的插孔编号均为 1、2、3、4，互不共享设备 ID。

线缆由直线和局部圆滑二次曲线组成，避免自由样条越过背板；分别布置四条后方理线通道。高位设备走柜外侧，再从开放前侧进入柜格。

## 数据与交互检查

23 项独立回路检查通过，覆盖：每床断电归零、其他三床继续供电、单床恢复、同类电器独立负载、四床汇总等于全寝、16 设备汇总等于全寝、总开关、离寝模式和历史上限。

手机实测四号床位插排开关：本床位总功率归零，面板正常关闭；四个床位入口均在屏幕内，无横向溢出。

## 仍需如实说明

- 包围盒检查不是逐三角形碰撞测试，也不是所有动画帧与所有观察角度的数学无穿模证明。
- 焊接、插接、螺钉与板件的有意连接交叠不按穿模处理。
- 侧墙/背板采用建筑剖面表达；上铺可透明检查，透明模型会有有限的渲染排序差异。
- 电缆、插孔和保护开关是视觉演示，不验证真实电气拓扑与安全标准。
- 这些是细化的程序模型，不是扫描资产或写实工业 CAD。
- 自动化浏览器使用 SwiftShader；真实设备的帧率仍需要单独测量。
