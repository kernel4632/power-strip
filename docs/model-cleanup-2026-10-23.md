# 模型错位清理与床品修正

本轮只修改 3D 场景、材质和几何验证。不修改 UI、设备功率、实测工作簿或状态计算。

## 删除的错误表达

- 床后不可通行、又没有建筑开洞的假房门。
- 无侧墙支承的半片吊顶和悬挂灯具。
- 从护栏穿出的被片、悬空格纹条、球体叠出来的“被子褶皱”。
- 已关闭柜门内部的篮子、暖水瓶、悬空纸盒。
- 未跟随椅子变换的坐垫和靠包。
- 相互交叠的三本地面书、闲置主机底板和打印机托板。
- 用实心圆柱叠出的脸盆、竖着套在桶身上的圆环。

## 更正方式

- `clothGeometry.ts` 生成双面封闭的连续布面：被子在床尾沿床垫半径转折，枕头有边缘收拢和凹陷。所有床品限制在护栏内，不采用实时布料模拟。
- `Bedding.tsx` 使用低对比度纹理，格纹随 UV 贴合，不使用悬空几何线。
- `RoomObjects.tsx` 的脸盆和杯子使用带内壁的旋转截面；毛巾沿真实横杆连续折回，篮、球、垃圾桶和晾衣架按同一地砖上表面高度落地。
- 四把椅子保留不同结构；它们的座面、支腿、坐垫在同一个局部坐标系里。
- 书架摆件贴合搁板；桌面摆件避开笔记本、台灯、手机和平板。
- 台灯、窗光、墙灯提供光源依据，移除多处无来源的暖色点光。缩小接触阴影的高度范围，床位/昼夜切换时重新计算，避免缓存整张床的阴影。
- 材质合批保留接收阴影差异，避免原本不接收阴影的构件被错误合并。
- 平板变小后遗留的旧电源端口偏移已改为随模型缩放，未修改真实数据映射。线缆夹也从悬空位置移到线束高度。

## 可重复检查

```bash
npm run check:geometry
npm run lint -- --deny-warnings
npm run build:pages
```

`check:geometry` 包含四套被子/枕头的护栏净空、床板净空、有效法线、退化三角形、闭合网格边计数和毛巾连续性检查，也检查平板电源端口随物理底座缩放。该脚本已加入 Pages 预构建。

浏览器中的 `window.dormDiagnostics().geometry` 使用变换后的实际顶点计算边界，检查内容包括：

- 本轮 97 个有明确审计边界的对象，包括桌面、柜体、梯子、书架、椅子、摆件及 14 台电器。
- 支撑面高度偏差（容差 3 mm）。
- 明确标注区域的边界/净空。
- 同床位和跨床位/公共区域的摆件与家具、电器包围盒交叠。
- 14 根设备线缆的终点与设备边界距离；允许插头外壳的 11 mm 延伸，不允许线头脱离插头。

本轮浏览器结果为支撑面/边界问题 0、包围盒重叠 0、断开的设备线缆 0。另查看了四个床位近景、插排近景、床品近景、日夜全景和手机布局。

## 限制

这不是完整 CAD 校验：包围盒通过不等于对所有三角形、所有角度和所有动画帧证明绝不穿模。螺钉、支腿与座面、插头与外壳等预期连接可以有少量接触交叠；文字贴面允许亚毫米偏移以避免闪烁。桌后板保留有意的建筑剖面表达。没有把模型升级为扫描资产，也不承诺真机固定帧率。
